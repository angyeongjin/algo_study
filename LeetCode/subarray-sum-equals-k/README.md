# 560. Subarray Sum Equals K

- 플랫폼: LeetCode
- 난이도: Medium
- 문제: https://leetcode.com/problems/subarray-sum-equals-k

## 문제 설명

Given an array of integers `nums` and an integer `k`, return <em>the total number of subarrays whose sum equals to</em> `k`.

A subarray is a contiguous <strong>non-empty</strong> sequence of elements within an array.

<strong>Example 1:</strong>

```
Input: nums = [1,1,1], k = 2
Output: 2
```

<strong>Example 2:</strong>

```
Input: nums = [1,2,3], k = 3
Output: 2
```

<strong>Constraints:</strong>

- `1 <= nums.length <= 2 * 104`
- `-1000 <= nums[i] <= 1000`
- `-107 <= k <= 107`
